# JTab 商店描述（简体中文）

## 名称

JTab - 书签新标签页

## 简短描述

以浏览器书签为数据源的现代新标签页，支持多层文件夹、背景定制与自定义 CSS。

## 详细描述

JTab 将浏览器现有书签整理成清晰、流畅的现代新标签页，无需注册账号，也无需把书签上传到云端。

主要功能：

- 以收藏夹入口组织内容，子文件夹可在新标签页内逐级展开并排列直属书签。
- 自由选择需要展示的文件夹，可包含直接内容或完整子树。
- 设置直接在新标签页内打开，无需跳转到扩展管理页面。
- 支持详细卡片与方形图标两种书签布局，可分别调整收藏栏透明度、磨砂、书签卡片透明度和卡片圆角。
- 搜索框显示当前搜索引擎，并可就地切换 Google、Bing、百度或 DuckDuckGo。
- Fluid 主题针对大屏新标签页优化，兼顾信息密度、动效和操作效率。
- 支持内置背景、本地图片、HTTPS 远程背景和明暗调节。
- 提供标准化 CSS 变量及自定义 CSS，样式会在保存前校验。
- Chrome 和 Edge 使用浏览器本地 favicon；Firefox 使用离线文字字标兜底。
- 设置与图片仅保存在当前浏览器配置文件中。

隐私设计：

- 无账号、登录、云同步、广告、分析或遥测。
- 不收集或上传书签、搜索词和使用行为。
- 不访问书签网站的 `/favicon.ico`，不调用第三方 favicon 服务。
- 自定义 CSS 禁止加载远程资源。

权限用途：

- `bookmarks`：读取并展示浏览器书签树。
- `storage`：在本地保存展示和外观设置。
- `favicon`：仅 Chrome/Edge 使用，读取 Chromium 浏览器本地网站图标。

支持 Chrome、Microsoft Edge 和 Firefox 桌面浏览器。Chrome 与 Edge 隐身窗口不允许扩展覆盖新标签页，这是浏览器平台限制。

## 单一用途说明

JTab 的唯一用途是把当前浏览器的本地书签组织并展示为可定制的新标签页。

## 数据使用声明

JTab 不收集、不传输、不出售用户数据。Firefox 包声明 `data_collection_permissions.required = ["none"]`。
